# NUTS.jl

No-U-Turn Sampler transitions for a user-supplied log density and gradient,
with an explicit step size and metric.

[Start](https://nsiccha.github.io/NUTS.jl/dev/) ·
[Gaussian example](https://nsiccha.github.io/NUTS.jl/dev/examples/gaussian) ·
[API](https://nsiccha.github.io/NUTS.jl/dev/reference/api)

The [documentation build](docs/README.md) executes the examples.
The [historical timing experiment](bench/README.md) is maintained separately.
